## 3. 新方法及其边界

### 3.1 有限邻载

新增有限宽无限长条带、有限矩形地面荷载。荷载位置、强度、长度和每阶段活动清单均冻结。矩形沿墙方向起止位置必须明确；长度65m不会自动变成剖面居中的±32.5m。

选用方法的身份为`boussinesq_vertical_rankine_k_mapping_v1`：先计算弹性半空间竖向应力增量，再映射到指定层的K0、Ka、Kp。其本质和直接横向应力法不同，不能仅因峰值接近而认定为FRWS原方法。[3]

条带近、远边距为a、b时：

\[
\Delta\sigma_z=\frac q\pi\left[\arctan\frac bz-\arctan\frac az+
\frac{bz}{b^2+z^2}-\frac{az}{a^2+z^2}\right].
\]

矩形采用Boussinesq点荷载核在明确面积上的积分；生产实现为解析角点式，独立测试采用二维数值积分。同冻结快照手算核对另采用沿墙方向解析积分及变换后的48/96点Gauss积分，不调用生产角点函数。

独立小算例q=30kPa、a=4.3m、b=16.3m、z=4.9m，若明确假设沿墙居中65m，矩形增量为3.2244485233kPa，无限长条带为3.2318455941kPa。四个矩形算例与独立100×100积分最大绝对差5.33×10⁻¹⁵kPa。**这些是方法算例，居中假设不是原项目确认条件。**

### 3.2 土水合算、分算

每层分别冻结`effective_separated`或`total_combined`及其c、φ、K0参数口径。总自重竖向应力先完整积分，物理孔压单列，有限邻载增量另列。

- 分算：以有效应力计算土压力，外部水压力单独施加一次。
- 合算：以总应力及明确总应力参数计算总侧压力，不再添加一次水压力。
- 压力导出同时保留实际物理孔压`waterPressureKpa`与实际施加的`externalWaterKpa`，后者在合算层为0。

φ=0退化等值、混合土层、跨水位自重积分和水压计一次均有专属回归。更换应力法不自动改变参数物理意义；缺少有效/总应力参数依据时拒绝输入。

### 3.3 坡台

已实现**干燥、均质、c=0、光滑竖直墙**下的折线坡面主动楔体合力核验。平地面退化例H=6m、γ=18kN/m³、φ=30°得到Pa=108kN/m、滑裂角60°；加q=10kPa得到128kN/m。坡台例与独立密集试楔扫描一致。[4]

这只给出该适用域下的主动合力；尚未构造原项目分层含水坡台的侧压力分布、初始压力、被动上限和位移相关抗力。因此没有把该合力随意摊成三角形并接入原项目阶段模型。这是明确待开发的物理模型边界。

### 3.4 卸载与阶段重置

新增三种具名、不可隐式切换的历史规则：

|规则|下一阶段土弹簧历史偏移|同一小算例第二阶段u / p|
|---|---|---|
|继承历史|上一收敛塑性位移|0.09m / 90kN|
|塑性偏移归零|0|0.065m / 115kN|
|以当前位移重建土体参考|有方向的上一收敛位移|0.14m / 40kN|

手算为`1000u + clip(50 + 1000(u-offset),20,150) = 180`。主核和真实OpenSees分别计算并吻合。土体重置不会把墙体或已安装支撑的参考位移归零；只有收敛状态进入后续阶段。支撑安装、拆除和土体重置不允许混为一个事件。三种规则是已定义的方法选项，**不是已证实的FRWS9.0默认选项**。

## 4. 原项目逐阶段全曲线比较

实现的原数值导入格式为`pitguard.reference-curves/1` JSON。CSV只有表头及人工转换说明，不是原软件解析器。空模板含原项目五个阶段，所有节点样本均为空，绝不以报告的min/max补造曲线。

输入曲线先声明坐标原点、方向、换算、单桩/每米墙宽、符号、特征/设计效应、压力组成、原输出位置与来源，再进行数值比较。只有原项目条件绑定正确，才可能建立同条件结论。

比较包含坑内外压力、u/M/V、水平支点反力、安装参考位移、设计系数、设计需求、配筋面积和控制阶段。实体支撑轴力是独立指标，不能把沿墙反力直接当成支撑杆件轴力。

比较采用两方节点深度及上下侧的并集，只在有效覆盖区间插值，不外推，不跨越未采样的层界或集中反力跳跃。输出最大绝对差及位置/侧别、偏差、RMSE、极值位置、缺样、缺边界、覆盖比例、缺失长度和并列控制阶段。近零段使用绝对误差阈值，不能用相对误差掩盖符号和小剪力问题。

当前主程序土压力是固定Gauss站上相邻节点的加权恢复，明确标注投影身份，不伪造墙端或层界值。位移/弯矩/剪力覆盖与压力投影覆盖分开报告；压力投影不同且未建立有依据的转换时，全曲线验收保持未通过。

保存比较必须绑定输入快照、分析结果、条件合同、原曲线包及比较记录五个身份。已保存比较缺依赖文件时直接报错，不能静默退回“没有做过比较”。导出只消费封存结果，不重新运行结构求解。

2. 参数与计算选项导出或逐页截图：E、EI折减、m定义及层间处理、有效宽度、桩端/桩顶、冠梁组装、支撑刚度与安装/拆除规则、卸载/重置选项。
3. 坐标、水位、坡台折线、有限邻载相对剖面的实际位置；核实−0.8m局部水位及上覆土水头的实现。
4. 所有原阶段节点u/M/V、两侧压力、支撑水平反力及安装参考位移；明确单桩/每米、正号、特征/设计值，保留原文件字节。
5. 原配筋采用值、材料强度、系数、使用组合、裂缝方法、节点连接与锚固起算位置。

先做原软件单梁、单弹簧卸载、单支点安装等诊断例，确认方法差异，再接坡台与原阶段；每次只改变一个有来源的选项。差异归因应落在压力组成、边界、刚度、离散和阶段状态，而不是调参凑峰值。

## 9. 静态知识与模板的具体落点

本轮已经落地三类静态资产：原文证据合同、明确语义的空曲线模板、以及带来源和独立小算例的方法模块。后续应继续分开维护：

- **原项目事实库**：原PDF/DWG/原生文件只读归档；以文件hash+物理页码+字段定位保存原值、解释、确认和变更。向量检索只用于找到原文，不能用检索摘要代替计算输入。
- **方法与规范规则卡**：用版本化JSON/YAML描述方法ID、规范版本、条款、适用域、单位、公式、必需参数、反例及测试；Python负责确定性求值。历史复现依据和当前工程复核依据分开。
- **成果模板**：DOCX/OMML保存计算展开和表格语义；DXF保存有依据的尺寸与节点参数；任何图元必须能回指输入/结果字段。缺连接条件的节点应停在待补，不让语言模型画出看似完整的施工详图。

智能体适合组织资料、提示缺项、解释差异、编排已授权的冻结计算和生成审阅包。数值求解、单位转换、验算状态及正式采用判断必须遵循这些有版本的确定性接口；不能让模型生成一个“通过”覆盖证据缺口。
