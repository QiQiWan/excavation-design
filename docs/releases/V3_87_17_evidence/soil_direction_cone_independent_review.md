# P2 方向锥修复：独立数学复核

范围：V3.87.17 中主求解器 `_check_directional_restraint` 与独立适配器 `_check_final_tangent_restraint`。本次未改产品代码，仅阅读实现并新增本证据、独立判定探针及其运行记录。

## 结论

在本模型声明的正 EI、连续 Euler–Bernoulli 梁、非负弹簧切线和确切位移约束条件下，方向锥判据的符号和候选方向枚举正确。本次没有发现将完全塑性平台误放行为唯一平衡的反例。对 1,029 组离散约束配置，两个实现均与独立的精确有理数可行性判定一致，差异数为 0。

此结论验证的是阶段本构的约束分类及其非零零刚度方向判定，不是整套阶段数值精度、土参数有效性或工程稳定验算的证明。

## 数学检查

正 EI 连续梁的零弯曲能量位移恰为仿射刚体模式：

\[
v(z)=a+b\xi,\qquad \xi=(z-z_{mid})/L.
\]

各构件零增量刚度的方向条件为：

| 构件或分支 | 零增量刚度方向 |
| --- | --- |
| 区间内部弹性土弹簧、双向弹性支撑、既有确切横向位移约束 | \(v(z_i)=0\) |
| 桩端转角约束 | \(b=0\) |
| 恰在土压力下界 | \(s_i v(z_i)\le0\) |
| 恰在土压力上界 | \(-s_i v(z_i)\le0\) |
| 土压力试算值严格越界 | 无局部约束 |
| 只受压支撑闭合且相对位移为零 | \(v(z_i)\le0\) |
| 只受压支撑正间隙压缩量 / 负间隙张开量 | 分别为 \(v(z_i)=0\) / 无局部约束 |

这里使用上一提交塑性偏移得到的 trial，而非只看已截断的 pressure。完全平台点的实际压力虽然也落在界限上，严格越界 trial 仍被忽略；不能把这些点重新当成单向角点。互补上下界则保留各自相反的方向约束，从而能够共同限制刚体模式。

若等式约束矩阵 E 秩为 2，刚体模式只能为零；若秩为 1，只需检查其零空间的正、负两个方向。E 为空而 H 非空时，二维非零闭多面锥必有某条约束边界射线，因此枚举各 H 行法向的正、负垂线足够。H 也为空时任意非零方向都可行。使用闭半平面是必要的：边界射线本身也可能构成平台运动，不能只检查严格内部。

64 倍机器精度的界限容差只从区间内部将双向弹性分支降为单向角点，严格越界 trial 不提升为角点。正的方向容差和近相关等式的降秩处理主要产生保守误拒风险；本测试不对极近退化几何给出位移误差界。方向锥闭合仅排除零刚度方向，不能替代条件数和残差精度检查。

只读检查还确认独立适配器的 ModifiedNewton 初始矩阵重试会先完整重建原材料和上一提交偏移，不继承失败试算状态；残差仍使用真实材料力。本次探针未执行 OpenSees 原生求解，不把这一代码检查写成原生回归测试已通过。

## 独立精确判定与覆盖

探针 `verify_soil_direction_cone.py` 标记为 verification-only，不进入产品计算路径。精确判定使用 Python `Fraction`，依次固定 \(a=+1,-1\) 或 \(b=+1,-1\)，把其余变量的等式和半平面约束化为一维有理数区间交集。任意非零齐次锥成员都能通过正比例缩放落入其中一种情况。这条判定路径不复用产品实现的垂线枚举算法。

节点深度为 0、0.5、1 米；每个节点枚举无土、坑内下界、坑外下界、互补下界、内部弹性、严格平台、互补上界七种配置，再组合 free/pinned/fixed 三类桩端，共 \(7^3\times3=1029\) 组。

实测：**743 组只有零零刚度方向，286 组存在非零零刚度方向；两个实现均与精确判定一致，0 项差异。** 压缩支撑分支完成了上述符号推导，但未纳入本穷举；本探针也未替代完整阶段平衡求解。
