# 原项目计算条件、方法差异与工程检查设计

## 已授权目标

用户要求继续执行上一轮的四项工作：固定原项目条件，实现原项目实际存在的方法差异，逐阶段比较完整响应，补充工程配筋验算并据此扩充成果。基线为已交付 V3.87.17 / c8793e8。沿用现有隔离工作区，新分支 original-project-validation。原始文件和上一版快照不得改写。

## 方法选择

原生 FRWS9.0 工程尚未识别，公开资料也没有确认其原生格式与全部历史求解选项。当前可行路径是分别建设有来源的条件合同、明确适用域的作用计算、完整曲线交换与比较、工程截面检查，再接入既有冻结求解和成果链。直接将现行软件说明套用到历史9.0会改变比较条件；完整连续土体有限元也不能自动补足原设置，且超出本轮已有梁土系统的任务边界。

新功能采用独立模块，保留 v1 快照及旧成果读取；新增求解选项使用 v2 输入并冻结算法身份。新方法和新输入不得静默改写旧快照。

## 工程约束

- 原值、单位换算/工程推导、尚未确认条件分别存储，缺项保持 null。确认必须带用户提供的来源记录，不自动生成设计人签认。
- 原报告软件是同济启明星 FRWS9.0；FRWS10/11 新增功能不能当作9.0已知能力。
- 原地面与桩顶相差1.3m。原开挖/支撑/水位的转换保存原值和推导，不能直接替换原记录。土层不能裁去上方1.3m后省略覆土与坡台作用。
- 历史规范、原组合与现行工程检查依据分别冻结。
- 有限条带/矩形邻载采用明确的弹性半空间竖向应力影响与K映射；不声称自动等同FRWS9.0。
- 土水分算/合算的选择作用于当前材料站的应力定义。总自重和孔压各自完整积分，防止穿越不同层时重复或漏算水。
- 真坡台楔体计算先作为独立作用核验。若只确定主动合力，不能自行给出K0/被动及连续压力分布并塞入双侧弹塑性求解。
- 历史继承、塑性偏移清零、重设到当前位移三种规则必须显式区分；原规则未知时保持假设状态。
- 全曲线比较必须同时核查来源、条件哈希、阶段映射、标高基准、正负号、特征/设计口径、单桩/每米单位及节点侧别。PDF极值不能伪造为原始节点曲线。
- 工程检查采用可核查的圆截面方法。规范允许的圆截面抗剪等效公式与任意矩形替代分开；裂缝方法不在已核实适用域时不得显示规范通过。
- 轴力、SLS组合、裂缝限值、环境/抗震/保护层与锚固条件必须显式提供。缺失不能默认零或默认常用规范值。
- 正式工程发行状态不由本轮程序测试自动解除。
