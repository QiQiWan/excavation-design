# 冻结剖面阶段分析与同源成果实施计划

## 已授权目标

在 3.87.16 的不可变复算与真实状态基础上，建立可核对的二维排桩剖面子系统。固定输入、土体抗力定义、阶段事件和单位；同条件与手算、独立 OpenSees 求解器比较；从同一输入与结果快照生成最小计算书、剖面图、内力包络及配筋表。保留原全基坑引擎的模型限制，不把本子模型的验证迁移为全系统通过。

## 方法决定与范围

1. 单桩 Euler–Bernoulli 梁，真实圆截面 I=πD⁴/64，实际桩距单独定义。土压力荷载按桩距归集，土弹簧有效宽度独立冻结。
2. 双侧独立理想弹塑性 Winkler 弹簧。坑内压入方向 s=+1，坑外 s=−1；以有效应力 K0 压力为初态，主动/被动 Rankine 压力为界限。p_trial=p0+k(su−x_pl,committed)，p=clip(p_trial,p_a,p_p)。水压力作为外荷载只出现一次。提交收敛阶段后更新塑性位移；迭代中不可重复累积。该方法是局部弹簧近似，不声称代表完整连续土体应力历史。
3. 初始两侧地面、水位、土层一致，无附加荷载，初始平衡由方程自然得到。施工中坑内已挖弹簧删除，存续弹簧材料身份不变；其 p0、m 深度与压力界限按已冻结的阶段规则重算。
4. 支撑零预力安装，记录安装前位移。弹性支撑 R=K(u−u_install)，可选只受压；刚性换撑为真实非零位移约束。新支点安装与拆旧撑必须分事件。非零预力暂不接受，避免混淆安装前初始弹力与锁定实测预力。
5. 本轮为平地垂直排桩、分层有效应力、静水压力、均布地面荷载、二维横向弯曲。坡台、有限宽邻载、土水合算、空间效应、竖向荷载、施工土体损伤、地表沉降、渗流和稳定验算不在已验证范围。
6. 特征阶段独立求解完整历史。设计内力采用显式冻结的效应系数乘特征内力，标注其来源；不把位移乘系数伪称设计位移。圆形配筋采用显式材料曲线的数值应变协调检算，给定配筋与需求分开；其适用范围和未覆盖的剪切/裂缝/构造检查逐项列出。

## 计算合同

公共输入为严格 Pydantic 冻结模型，禁止未知字段、非有限数与缺失参数默认修补。快照保存规范 JSON 与 SHA256；分析身份另含算法版本与网格配置。返回副本不修改快照。输出带 snapshotHash、analysisHash、resultHash。

内核 solve_stages(model) 接口：model 包含 nodesM、eiKnM2、toeBoundary、stages。每阶段含 id/name/event、externalForcesKn、soilSprings、installSupports、removeSupports。土弹簧字段为 id/node/sign/p0Kn/kKnPerM/lowerKn/upperKn/side/depthM；支撑字段为 id/node/kind/stiffnessKnPerM/compressionOnly/preloadKn。节点横向位移向坑内为正，深度向下为正；梁转角为 du/dz。

内核每阶段返回 nodalDisplacementM、nodalRotation、elementEndForces、soilStates、supportStates、收敛/平衡指标。每根梁端力定义 [Vi,Mi,Vj,Mj]，对应其局部刚度矩阵与自由度 [ui,θi,uj,θj]。服务层明确定义截面 M/V 符号，保留节点左右侧及控制阶段，避免支撑处剪力跳跃被插值抹平。

## 并行职责

- 主代理：输入合同、不可变快照、压力/网格预处理、结果与配筋、服务/API/轻量入口、集成、发布。
- 力学代理：梁刚度、双侧弹塑性阶段求解、状态/失效门禁及解析测试。
- 独立求解器代理：原资料证据账本、独立 OpenSees 建模及同条件比较。
- 成果代理：仅消费冻结快照与结果的 DOCX/PDF/DXF/包络/CSV/清单；尺寸、比例、排版检验。

## 结果验证与验收

先锁定测试与容差，再观察结果。解析梁子问题位移相对误差 ≤0.1%；同一离散模型独立求解器位移/内力误差 ≤0.1% 并设近零绝对阈值；总力/力矩平衡相对误差 ≤1e−6；网格减半的主要响应差异目标 ≤2%。所有差异逐指标输出，失败/缺失不得转成通过。

施工事件检查：初始自然平衡、零力安装、加载后反力、拆撑重分配、刚性换撑参考位置、屈服后卸载残余、塑性历史只提交一次。比较工具不调用主求解器刚度矩阵，不读取主求解结果回填独立值。

原 A3-3 参考 PDF 已证实包含坡台、有限宽邻载、土水合算和未明确的软件设置。本轮建立已知事实与缺项清单，不用默认 E、m 公式、桩端条件或弯矩宽度身份冒充原项目同条件通过。原生模型未交付时状态保持 incomplete。

同源成果检查：篡改/混用快照必须拒绝；计算书、剖面、包络、配筋表全部使用同一 resultHash；真实尺寸测量与固定比例应一致；所有页渲染目视检查。输出为可复核的剖面验证成果，正式施工出图门禁保留。

## 实施顺序

1. 保留 3.87.16 本地基线并建立独立工作区（已完成，基线 6204f17）。
2. 冻结模式与输入校验，建立完整的验证样例及原资料差项。
3. 梁/土/支撑阶段内核与独立求解器并行实施。
4. 同条件比较、网格收敛、最终带符号包络和圆截面配筋一致性。
5. 同源最小成果包、API 与清晰入口。
6. 独立代码审查、针对风险的回归验证、文档、完整源代码与样例交付。
